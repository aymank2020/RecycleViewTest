# RecycleViewTest

## New educational foundation

The original public revision contains an incomplete Android skeleton without an
app module or wrapper. Remote branches, tags, the original commit tree and fork
metadata provided no recoverable application source. **This branch establishes a
new example; it does not claim to restore the missing original application.**

The example follows the original repository description: a horizontal RecyclerView
and a photo grid. Eight local shapes and colors provide the imagery; there are no
downloaded photos, network APIs, accounts, storage permissions or third-party media.
Click a shape to share its selection between the row and grid. The hide/show button
exercises the empty state. Selection and visibility are saved across Activity recreation.

Run `powershell -File scripts/check-project.ps1` for a reproducible structural check.
It checks required source and wrapper files without changing the project. File
presence is a structural check, not proof that an APK builds or runs.

## Build and checks

Use JDK8, Gradle5.6.4, Android SDK platform29 and Build-Tools29.0.2. The known
working legacy toolchain is pinned for this foundation; modernization is a separate
step before production distribution. Set JAVA_HOME and ANDROID_HOME, or configure
the SDK in your local untracked local.properties.

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest --no-daemon --max-workers=2
```

The wrapper is generated by the verified official Gradle5.6.4 distribution. Its bin
download is checked against distributionSha256Sum. The app uses AGP3.5.1 and
RecyclerView1.0.0 and Core1.0.1, matching dependencies already validated in this review environment.
The default JVM heap is1GB with two workers to limit resource use.

For an existing trusted local Maven mirror, pass
`-PofflineMavenRepository=<absolute-directory>` together with `--offline`. This
optional directory is searched before Google and Maven Central. No local cache
or machine-specific build configuration is committed to the repository.

Unit tests cover catalog identity, selection restoration, repeated hide/show,
invalid/hidden selection and immutable data. They do not simulate Android touch,
scroll or rotation. See [the Arabic review](DEVELOPMENT_REVIEW_AR.md) for actual
APK build results, evidence and outstanding device checks.

On a device, launch "معرض الأشكال", scroll the horizontal row and grid, select
from each, hide/show twice, then rotate. The selected shape should stay selected in
both lists, without duplicate items. No device or emulator is started by the tests.
See the [Gradle Wrapper guide](https://docs.gradle.org/current/userguide/gradle_wrapper.html).
